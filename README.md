# NHL Analytics Dashboard
An interactive dashboard for analyzing NHL team performance.

## Features
- Team standings and rankings
- Momentum score for performance analysis
  - Momentum score combines win percentage, goal differential, and offensive production.
- Team comparison tool
- Historical performance comparison

## Tech Stack
- Python
- pandas
- Streamlit
- Plotly

## How to Run
pip install requirements.txt

streamlit run app.py
